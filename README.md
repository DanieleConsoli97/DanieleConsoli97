<h2 align="center">🚀 What I'm working on</h2>

| Project | What it is | Stack |
|---|---|---|
| **[Centraly](https://centraly.it)** | Multi-tenant Property Management System for hotels and hospitality, in production with real customers (team project): bookings, quotes, guest check-in, Stripe Connect payments, Italian e-invoicing (SDI), ISTAT reporting, public booking engine | Node.js · Express 5 · PostgreSQL (RLS) · React 19 · Redux Toolkit · Tailwind CSS |
| **[Medora Studio](https://medorastudio.it)** | Multi-tenant SaaS for nutritionists and dietitians, built solo: patient records, nutrition calculations, 8,000+ food database, healthcare invoicing, Sistema TS submission, patient PWA | TypeScript · React · Express · PostgreSQL (RLS) · Zod · Stripe · Docker |
| **[SamoTech Store](https://samotechstore.com)** | Bilingual PC hardware e-commerce with a custom theme and a plugin that syncs the supplier catalogue automatically | WordPress · WooCommerce · PHP 8.3 · MariaDB · Docker |
| **Fitness Pro** | Platform for personal trainers and clients: JWT + refresh tokens, passkeys (WebAuthn), 2FA, Stripe, real-time notifications, Prometheus metrics | Node.js · Express 5 · PostgreSQL · Redis · Socket.io |
| **appointments-core** | Reusable multi-tenant, multi-resource booking engine: DST-safe slots, recurring bookings, idempotency, state machine with audit trail | TypeScript · Express · PostgreSQL · Luxon · Vitest |

<sub>Most of these repositories are private (client and product code). Happy to walk through the code in an interview.</sub>
